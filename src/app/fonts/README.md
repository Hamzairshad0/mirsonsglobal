# Fonts

Self-hosted variable fonts (Latin subset), loaded with `next/font/local` in `src/app/layout.tsx`.

| File | Font | Weights | Source |
| --- | --- | --- | --- |
| `inter-latin-wght-normal.woff2` | Inter | 100–900 | `@fontsource-variable/inter` 5.3.0 |
| `playfair-display-latin-wght-normal.woff2` | Playfair Display | 400–900 | `@fontsource-variable/playfair-display` 5.3.0 |

bundling them with websites and software.
